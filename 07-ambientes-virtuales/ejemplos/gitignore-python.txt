# Plantilla de .gitignore para un proyecto de Python / ML
# =============================================================================
# En tu proyecto este archivo se llama ".gitignore" (con punto, sin extensión)
# y va en la raíz del repo. Aquí se llama gitignore-python.txt para que no
# afecte a esta carpeta de ejemplos.
#
# Cada línea es un patrón: Git NO rastrea los archivos que coinciden.
#   carpeta/   -> ignora la carpeta entera
#   *.ext      -> ignora todos los archivos con esa extensión
#   !archivo   -> EXCEPCIÓN: vuelve a incluir algo que un patrón anterior ignoró
# =============================================================================
